## 2. 产品定义

### 2.1 产品目标

**一句话目标**：将当前「能跑但不好用」的麻将原型，打磨成「UI 清晰美观、操作流畅顺手、规则准确完整」的可玩产品。

**具体目标**：
1. **UI 可用性质变**：从「文字牌面 + 空白绿底」升级为「图形化牌面 + 信息丰富的牌桌」，让玩家一眼看懂局势。
2. **操作体验流畅**：出牌/碰杠胡操作直观、反馈即时、移动端可玩。
3. **玩法规则完备**：修复已知规则缺陷（一炮多响等），补全边界情况，AI 不再「太蠢」。
4. **多端适配可用**：桌面端体验舒适，移动端（手机浏览器）基本可玩。

## 5. UI 设计方向

### 5.1 设计语言建议

**整体风格**：「精致国风桌游」— 保留现有绿色牌桌基底（`--felt: #0b6b3a` 是好的起点），提升质感。

### 5.2 配色方案（基于现有 CSS 变量扩展）

```
现有（保留）:
  --felt: #0b6b3a        ← 牌桌绿（好）
  --felt-dark: #074d2a    ← 牌桌深绿（好）
  --gold: #f5c542         ← 金牌/强调色（好）
  --tile-bg: #fbf7ec      ← 牌面米白（好）

建议新增:
  --felt-light: #0d8a4a   ← 牌桌亮区（高光）
  --felt-felt: url(...)   ← 牌桌纹理（毡布/木纹）
  --danger: #e74c3c       ← 危险/胡牌红（替代硬编码 #ff5a5a）
  --success: #27ae60      ← 安全/通过绿
  --muted: rgba(255,255,255,0.55)  ← 次要文字
```

### 5.3 牌面呈现（核心改进）

**现状问题**（见 `06_ningde_playing.png`）：26×36px 文字牌，`3 万` / `发` 等在小字号下极难辨认。

**改进方案**：

| 属性 | 现状 | 建议 |
|------|------|------|
| 尺寸 | 26×36px（桌面）/ 22×31px（移动） | 40×56px（桌面）/ 34×48px（移动） |
| 内容 | `<span class="num">3</span><span class="suit">万</span>` | Unicode 麻将字符 🀇🀈… 或 SVG 图标 |
| 金牌标识 | `outline: 3px solid gold`（细线） | 金色边框 + 微光晕(`box-shadow: 0 0 12px gold`) + 角标「金」 |
| 牌背 | `linear-gradient(135deg, #2a7d4f, #1c5f3a)` + 方框 | 统一麻将背纹（可用 CSS repeating-linear-gradient 模拟） |
| 选中态 | `.tile.sel` 已定义但**未使用** | 上浮 8px + 金色粗边框 + 轻微放大(1.05x) |
| 可出牌态 | `.tile.discardable:hover` 上浮 5px | 增加 cursor-pointer + 轻微发光 |

### 5.4 布局改进

```
┌─────────────────────────────────────────────┐
│  [川麻(血战)]  [房间 K72EX]  [座位 1]  [退出] │  ← topbar（已有，增加分数汇总）
├──────────┬──────────────┬───────────────────┤
│          │              │                   │
│  左玩家   │   中央信息区   │    右玩家         │  ← 四座位（增加活跃指示）
│  AI ★    │  剩余: 55     │    AI             │
│  手牌:13  │  轮到: 测试   │    手牌:13         │
│  分数:+2  │  金牌: 6筒    │    分数:-5         │
│          │              │                   │
│  [弃牌区] │              │    [弃牌区]        │
├──────────┴──────────────┴───────────────────┤
│           [3万][4万][5万]...[9条][发]        │  ← 自己的手牌（加大）
│              请出牌（点手牌）                 │  ← actionbar
│     [  胡  ]  [ 暗 杠  ]                      │  ← 操作按钮（增大+图标）
├─────────────────────────────────────────────┤
│  测试 自摸胡 平胡 门清 自摸 +6               │  ← log（增高）
└─────────────────────────────────────────────┘
```

**关键改动**：
1. 每个座位旁增加**实时分数显示**（数据已在 `state.players[].score` 中）
2. 中央信息区增加**当前玩家高亮箭头**指向对应座位
3. 弃牌区的**最后一张牌**加红色边框标记
4. 手牌区和动作栏之间留足间距，避免拥挤

### 5.5 交互动效（优先级排序）

| 动效 | 实现方式 | 时长 | 优先级 |
|------|----------|------|--------|
| 手牌选中上浮 | `transform: translateY(-8px)` + `transition: 0.15s` | 150ms | P0 |
| 出牌飞向弃牌区 | `FLIP` 动画或 `transform` + `opacity` | 300ms | P0 |
| 按钮按下反馈 | `transform: scale(0.95)` + `transition: 0.1s` | 100ms | P0 |
| 胡按钮脉冲 | `@keyframes pulse` (scale 1→1.05→1) | 1.5s loop | P0 |
| 发牌依次入场 | `animation-delay` 累加 (~50ms/张) | 50ms×N | P1 |
| 碰杠牌飞入 | 从来源位置 FLIP 到副露区 | 300ms | P1 |
| 胡牌庆祝 | CSS 粒子/烟花 + 牌面展开 | 1.5~2s | P1 |
| 座位切换高亮 | `box-shadow` 发光过渡 | 300ms | P1 |

### 5.6 移动端适配方案

**断点策略**：
- `≥ 760px`：当前桌面布局（优化后）
- `560px ~ 759px`：平板布局（适度压缩）
- `< 560px`：手机布局（重构）

**手机端关键改动**：
1. **手牌**：底部固定区域，横向排列，超出后可 `overflow-x: auto` 滑动；每张牌 ≥ 34×48px
2. **座位**：上/左/右三对手牌区缩小或隐藏背面（仅显示张数数字）
3. **动作栏**：固定在屏幕底部，按钮竖排，每个高度 ≥ 44px
4. **中央信息**：简化为一行「剩余 XX \| 轮到 XXX」
5. **弃牌区**：缩小为 mini 牌（20×28px）或折叠为「查看」展开
6. **禁用双指缩放**（已有 `user-scalable=no`，好）
