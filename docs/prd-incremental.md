## 1. 变更目标

**一句话**：将当前「纯色绿底 + 方块 CSS 牌面」的朴素 UI，重构为接近参考图「雀神广东麻将」质感的桌面牌桌；同时修正宁德麻将牌池为 112 张、金牌固定为白板。

**具体目标**：
1. 牌桌视觉从「像没加载完的网页」升级为「有木纹边框 + 毡布纹理 + 牌墙的真实牌桌」，用户打开后第一眼有沉浸感。
2. 牌面从「带边框的白色方块」升级为「高对比真实图案牌」（筒=同心圆、条=竹节、万=汉字），一臂距离清晰可辨。
3. 宁德麻将牌池从错误配置修正为严格的 112 张（万/筒/条各 36 + 白板 4），引擎和前端完全对齐。
4. 金牌机制从「骰子翻金」改为「固定白板为金」，前端金框提示、后端百搭判定均正确映射到白板。
5. 四方位玩家座位 + 中央信息盘 + 弃牌区布局完整，信息密度接近参考图水平。

### 4.4 字体与牌面风格建议

### 4.5 牌面图案技术选型建议

**推荐方案：CSS 绘制（优先）**
- 筒：`radial-gradient` 同心圆，1 筒单一大圆，2~9 筒多圆组合（用 background 多层 gradient）
- 条：`repeating-linear-gradient` 竖线 + `background-size` 控制竹节数量，或用伪元素 `::before/::after` 画短线模拟竹节
- 万：纯 CSS 不可行，用大号中文字体 + 颜色解决
- 白板：空白 + 金色 border + box-shadow glow

**备选方案：SVG inline（如果 CSS 过于复杂）**
- 每种花色一个 SVG template，通过 `<use>` 或 JS 克隆
- 更精细控制图案布局，但增加了 DOM 复杂度

**不推荐：图片精灵**
- 增加网络请求/资源体积
- 缩放模糊
- 维护成本高
